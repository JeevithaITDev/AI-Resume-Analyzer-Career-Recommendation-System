# AI-Based Resume Analyzer & Career Recommendation System

An AI-powered web application that analyzes resumes and provides personalized career recommendations based on the skills, education, and experience identified from the uploaded resume.

## 🚀 Features

- Upload resume in PDF format
- Extract text from resumes automatically
- Analyze resume content using AI/ML techniques
- Identify skills and keywords
- Recommend suitable career roles
- Display resume analysis results
- Simple and user-friendly web interface
- Flask-based backend

## 🛠️ Technologies Used

- Python
- Flask
- Machine Learning
- Natural Language Processing (NLP)
- PyPDF2
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript
